5. CARA MENJALANKAN APLIKASI SECARA LOKAL
--------------------------------------------------------------------------------
1. Pastikan PHP >= 8.3 dan Composer sudah terpasang.
2. Buka terminal di folder proyek hasil ekstrak ZIP:
   composer install
3. Salin konfigurasi environment:
   cp .env.example .env
   php artisan key:generate
4. Buat file SQLite (jika belum ada) lalu jalankan migrasi & data awal:
   php artisan migrate --seed
5. Jalankan server pengembangan lokal:
   php artisan serve
6. Buka browser dan akses http://127.0.0.1:8000

Untuk mengaktifkan respons live fitur Konsultasi AI di lokal, isi
GEMINI_API_KEY pada file .env. Pada versi live hosting (alpetbizz.vercel.app),
GEMINI_API_KEY sudah aktif dan siap diuji langsung.
